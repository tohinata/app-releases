# 테마 (다크 공통)

안드로이드 `Ui.kt` 기준. PC·웹앱도 같은 HEX.

| 이름 | HEX | 용도 |
|------|-----|------|
| BG | `#121212` | 배경 |
| CARD | `#1C1F23` | 카드 |
| LINE | `#2A2D31` | 구분선·테두리 |
| TEXT | `#ECEFF1` | 본문 |
| SUB | `#9AA3AB` | 보조 글자 |
| BRAND | `#4FC3F7` | 강조·주요버튼·링크 |
| ACCENT | `#26A69A` | 보조 강조 |
| OK/WARN/DANGER | `#66BB6A`/`#FFB74D`/`#EF5350` | 정상/주의/위험 |

## UI 원칙
- 다크만. 밝은 테마 없음.
- 외부 UI 라이브러리 없음(안드로이드는 `Ui.kt` 헬퍼로 뷰 생성).
- 모서리: 버튼 ~10dp, 카드 ~14dp(CARD 배경 + LINE 1dp).
- 버튼: 채움=강조 / 외곽선=보조.
- 좌우 패딩 16dp. 글자 제목~22·소제목~17·본문~13–15·보조~12. 강조는 Bold.
- 상태색(OK/WARN/DANGER)은 의미로만.
