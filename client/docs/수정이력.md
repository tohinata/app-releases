# 수정 이력 (CHANGELOG)

프로젝트 루트 `CHANGELOG.md`. 앱 "수정 이력" 화면 + 업데이트 안내창 notes 의 출처.

## 포맷 (최신이 위, UTF-8 BOM 없음)
```
# 수정 이력

## 1.15.0 — 2026-10-15
- 사용자가 체감하는 변화를 사용자 말로
  - 필요하면 하위 항목
```
- 버전 절: `## <버전> — <YYYY-MM-DD>`. 내부 함수·파일명 쓰지 말 것.

## 자동 생성
배포 bat 이 그 버전 절이 없으면 **지난 릴리스 이후 커밋 메시지**로 만든다 → 커밋 메시지를 사용자 눈높이로 쓰면 그대로 체인지로그. 손으로 써두면 그걸 쓴다(중요 릴리스는 손으로 다듬기). `Get-Notes` 가 이 절을 manifest `notes` 로 전달.
