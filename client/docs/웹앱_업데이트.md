# 웹앱 업데이트

## Capacitor(안드로이드)
`모바일_업데이트.md` 와 동일(Java 업데이터). `platform:android`, versionCode, 전체 APK 덮어쓰기.

## HTML 폴더 앱 (client/web/update.ps1)
실행 bat 이 `update.ps1 -App <앱키> -Name <이름>` 호출. `version.txt` vs manifest(`platform:web`) → 새 버전이면 zip 받기→SHA-256→폴더 덮어쓰기→실패 시 롤백. 최신/오프라인이면 조용히 통과, **`.git` 개발 폴더면 건너뜀.**

## 크롬 확장 (client/chrome/update-check.js)
설치 `version` vs manifest → 새 버전이면 아이콘 NEW 배지 + 팝업 받기 배너(자동 설치 없음). 상태는 `chrome.storage`.

원본 수정: `client/web/update.ps1` / `client/chrome/update-check.js` 고치고 `9-1`.
