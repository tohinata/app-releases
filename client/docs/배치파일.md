# 배치 파일 체계

번호 bat 으로 더블클릭 개발·배포.

| 번호 | 뜻 | 예 |
|------|----|----|
| 0-x | 처음 설정 | `0-1_깃허브처음연결` |
| 1-x | 빌드 | `1-2_빌드`, `1-3_빌드정리` |
| 2-x | 설치·산출물 | `2-1_폰설치`, `2-3_APK만들기` |
| 3-x | git | `3-1_커밋+올리기`, `3-2`, `3-3` |
| 4-x | 배포 | `4-1_새버전배포` |
| 9-x | 허브 관리 | `9-1_공통업데이터복사`, `9-2_다운로드페이지갱신` |

## 인코딩 — 필수
bat 은 **CP949** 로 저장. 상단에 경고 주석 유지:
```
rem  This file is saved in CP949 ... Do NOT re-save it as UTF-8
```
UTF-8 로 재저장하면 콘솔 한글 깨짐(특히 VS Code 주의).

## 작법
`@echo off` → 경고주석 → `setlocal` → `title` → `cd /d "%~dp0"`. SDK/JDK 자동 탐색(ANDROID_HOME→LOCALAPPDATA, Android Studio jbr). 실패 라벨(`:no_sdk` 등)에 원인·해결을 한국어로. 끝에 `pause`(`nopause`/`nobuild` 인자 지원).
배포 bat 은 로직을 갖지 말고 `..\app-releases\tools\release-*.ps1` 호출.
