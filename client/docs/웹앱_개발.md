# 웹앱 개발 (Capacitor · HTML · 크롬확장)

`apps.ps1` 분류 기준 3종.

## Capacitor (웹+안드로이드 Java) — JavaApps
웹으로 화면, Capacitor 로 안드로이드 래핑. 업데이터 Java 판(`AppUpdater.java`+`UpdateReceiver.java`, `<Package>.update`), 설치 흐름은 모바일과 동일. 배포 `release-capacitor.ps1`.

## HTML 폴더 앱 (윈도우) — WebApps
정적 HTML/JS 폴더째. 실행 bat 이 열기 전 `update.ps1` 로 자동 업데이트. 버전=`version.txt`. 배포 `release-zip.ps1`. **`.git` 있는 개발 폴더는 업데이트 건너뜀.**

## 크롬 확장 — ChromeApps
버전=`manifest.json`. unpacked 라 자동교체 불가 → 새 버전이면 **아이콘 NEW 배지 + 팝업 상단 받기 안내**까지. 공용 `update-check.js` 를 `background.js`(importScripts)·`popup.html`(먼저) 로드. 권한 `storage` 만(raw 는 CORS 허용).

공통: 테마/개발자정보/수정이력 동일, manifest 주소·`?t=`·SHA-256 공통.
