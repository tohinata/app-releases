# 모바일 개발 (안드로이드 · Kotlin)

- Kotlin, **AndroidX 없이** 프레임워크 API. UI 는 `ui/Ui.kt` 헬퍼로 코드 구성(`테마.md`).
- 빌드 Gradle(`app/build.gradle.kts`, compile/target SDK 36), Android Studio JBR. 저장은 `org.json` + `filesDir`.

## 구조 (패키지 `com.coarsoft.<앱>`)
- `ui/` 화면 + `Ui.kt` (MainActivity·AboutActivity·ChangelogActivity·SettingsActivity 거의 공통)
- `data/` 저장소·동기화  · `update/` **공용 업데이터(직접 수정 금지, client 에서 복사)**  · 기능별 폴더

## 지킬 것
- AboutActivity 에 개발자/저작권(`개발자정보.md`), 수정이력 화면(CHANGELOG), 업데이트확인 `AppUpdater.checkNow(this,"<앱키>")`.
- `MainActivity.onCreate` 에 `AppUpdater.checkOnLaunch(this,"<앱키>")` 한 줄(포그라운드 복귀 확인은 업데이터가 알아서).
- 권한 최소 + 앱정보에 용도 한 줄. 접근성 서비스 쓰면 용도 명시·화면 안 읽음 고지.
- 제스처/좌표 기능은 화면 좌표라 세로/가로 일치 필요(보정 화면 패턴).
