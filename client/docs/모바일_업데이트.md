# 모바일 업데이트 (안드로이드)

공용 `update/AppUpdater.kt`(+UpdateReceiver), Capacitor 는 Java 판.

## 언제
- `MainActivity.onCreate` → `checkOnLaunch`.
- **포그라운드 복귀 때마다** 자동(업데이터가 `onActivityResumed` 에서 호출) → 접근성 서비스로 프로세스가 안 죽는 앱도 잡힘.
- **60초 throttle**(회전·설정복귀 무시). "업데이트 확인" 버튼 → `checkNow`(최신이어도 토스트).

## 동작
manifest `versionCode` 비교 → 크면 "새 버전" 창(notes) → [업데이트] → (처음이면 출처 허용) → **전체 APK** 받기 → SHA-256·패키지명 검증 → `PackageInstaller` **덮어쓰기 설치(데이터 유지)** → `USER_ACTION_NOT_REQUIRED` 시도(대개 기기가 1회 확인창) → 설치 후 앱 닫힘, 다시 열면 "업데이트했습니다" 토스트.
- 전체 APK(델타 아님), in-place(플레이스토어처럼 데이터 유지).

## 권한
`INTERNET`, `REQUEST_INSTALL_PACKAGES`, `UPDATE_PACKAGES_WITHOUT_USER_ACTION`, `<receiver .update.UpdateReceiver>`.

## 원본 수정
`client/android/AppUpdater.kt`(또는 `android-java/`)만 고치고 `9-1_공통업데이터복사.bat`. 앱별 복사본은 고치지 않음.
