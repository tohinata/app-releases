# coarsoft 공통 개발 문서

모바일·PC·웹앱 프로젝트가 공통으로 지키는 규칙. 공용 코드는 `client/`(android·android-java·windows·web·chrome), 규칙은 여기.

| 파일 | 내용 |
|------|------|
| `00-개요.md` | 전체 그림·공통 원칙·저장소 구조 |
| `개발자정보.md` | 표기·서명 주체·git 설정 |
| `테마.md` | 색 팔레트·UI 원칙 |
| `수정이력.md` | CHANGELOG 포맷·자동생성 |
| `커밋_푸시.md` | git 정책·서명키 백업 |
| `배치파일.md` | 번호 bat·인코딩 |
| `버전_릴리스_매니페스트.md` | 버전·릴리스 흐름·manifest |
| `모바일_개발.md` / `모바일_업데이트.md` | 안드로이드(Kotlin) |
| `PC_개발.md` / `PC_업데이트.md` | 윈도우(C#) |
| `웹앱_개발.md` / `웹앱_업데이트.md` | Capacitor·HTML·크롬확장 |
| `새앱_추가_체크리스트.md` | 새 앱 붙이기 |

각 프로젝트 루트 `CLAUDE.md` 에 "공통 규칙은 app-releases/client/docs 를 따른다" + 그 앱 특이사항만 적는다.
