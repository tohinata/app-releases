## 공통 원칙
1. 광고·추적 없음. 인터넷은 새 버전 확인·받기에만.
2. 외부 의존 최소 — 플랫폼 기본 API 우선(안드로이드는 AndroidX 없이 코드로 UI).
3. 데이터는 기기 안에. 내보내기/동기화는 사용자가 고른 파일·링크로만.
4. 다크 테마 통일(`테마.md`).
5. 스토어 없이 스스로 업데이트(`버전_릴리스_매니페스트.md`).

## app-releases 역할
- `client/` — 플랫폼별 공용 업데이터 원본 + 이 `docs/`
- `manifest/<앱키>.json` — 각 앱의 최신 버전 정보(앱이 읽어 판단)
- `releases` — 설치 파일(APK/zip) + 자동 생성 다운로드 페이지(README·apps/)
- `tools/` — 릴리스·동기화 스크립트. `apps.ps1` 이 앱↔플랫폼 정의

## 플랫폼(apps.ps1)
Android(Kotlin) · Windows(C#) · Java(Capacitor) · Web(HTML 폴더) · Chrome(확장). 새 앱은 `새앱_추가_체크리스트.md`.
