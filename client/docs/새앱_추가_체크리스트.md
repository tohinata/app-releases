# 새 앱 붙이기 체크리스트

1. `repos/<폴더>` 생성, 테마·개발자정보 적용, 패키지 `com.coarsoft.<앱>`.
2. `tools/apps.ps1` 해당 배열에 한 줄 추가(`Key` 소문자=태그·manifest 이름). Android 예:
   `@{ Key='<앱키>'; Folder='<폴더>'; Package='com.coarsoft.<앱>'; Name='<한글이름>' }`
3. `9-1_공통업데이터복사.bat` → `update/` 에 업데이터 들어옴.
4. 업데이터 연결: Android=onCreate `checkOnLaunch`+정보화면 `checkNow`+권한3종+Receiver / Windows=시작+메뉴 / Chrome=`update-check.js` 로드 / HTML=실행 bat 에서 `update.ps1`.
5. `CHANGELOG.md` 시작(`# 수정 이력`+첫 절).
6. bat 세트 복사·조정(CP949).
7. `0-1_깃허브처음연결.bat`.
8. `4-1_새버전배포.bat` — 서명키 자동 생성되면 **백업**.
9. 확인: 다운로드 페이지 반영, 앱에서 업데이트 확인 동작.
