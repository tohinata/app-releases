# 버전 · 릴리스 · 매니페스트

## 버전
- SemVer `주.부.수`. 안드로이드는 추가로 `versionCode`(정수, 매 릴리스 +1) — `build.gradle.kts`.
- 윈도우 `.csproj <Version>`, 웹앱 `version.txt`, 크롬 `manifest.json version`.
- 태그: `<앱키>-v<버전>`. 이미 있으면 배포 스크립트가 수 자리 +1 제안.

## 릴리스 흐름 (release-*.ps1, 4-1 bat 이 호출)
1. 버전 정하기(이미 올린 버전이면 +1 제안) 2. 미커밋 먼저 커밋 3. CHANGELOG 절 없으면 커밋메시지로 생성 4. 서명키 없으면 생성 5. 빌드(서명)→`dist/` 6. `gh release create` 7. `manifest/<앱키>.json` 갱신 8. 다운로드 페이지 갱신 9. 버전·CHANGELOG 커밋/푸시.

## manifest 필드 (UTF-8 BOM 없음)
```json
{ "app":"autoclicker","name":"오토클릭","platform":"android",
  "version":"1.15.0","versionCode":23,
  "url":".../releases/download/autoclicker-v1.15.0/AutoClicker-1.15.0.apk",
  "sha256":"…","size":831211,"notes":"- …",
  "publishedAt":"2026-10-15T13:19:52+09:00",
  "exe":"…","keep":["settings.json"],
  "portable":{"url":".../<앱키>-1.2.0-portable.exe","sha256":"…","size":0} }
```
- platform: android|windows|web (Capacitor 는 android). `versionCode` 는 안드로이드만. `exe`/`keep`/`portable` 은 윈도우 (`portable` 은 `-Portable` 로 올렸을 때만).
- 앱은 `raw.githubusercontent.com/tohinata/app-releases/main/manifest/<앱키>.json` 을 `?t=<분>` 붙여 읽음 → **갓 올린 직후 몇 분은 옛 버전 보일 수 있음**(raw 캐시).

## 비교
안드로이드=versionCode 정수 / 그 외=버전 문자열 숫자 배열(`1.2`<`1.10.0`).

## 다운로드 페이지
`pages.ps1`/`update-pages.ps1` 가 릴리스 때 README 표·`apps/<앱키>.md` 생성.
