### v1.9.11 — 영업시작 · 영업종료 방식 (2026-08-10)

- **영업시작**·**영업종료** 방식 추가 — 자식 버튼이 **요일(월·화·수·목·금·토·일)** 이고, 장소 홈의 영업 시간에서 그 요일의 시각만 복사
- 예: `화 18:00 - 다음 날 02:00` → 영업시작 `1800`, 영업종료 `0200` (콜론은 빼고 네 자리로, `9:30` → `0930`)
- 요일 목록이 **접혀 있으면 요약 줄(`오늘 …`)을 눌러 펼친 뒤** 읽고, 화면에 안 보이면 내리며 찾음
- `01:00 라스트오더` 를 종료 시각으로 잘못 읽지 않도록 **시작~종료가 함께 있는 줄만** 시간으로 인정하고, 다음 요일 줄을 만나면 멈춤
- 휴무인 요일(`월 정기휴무`)은 **휴무라 영업 시간이 없습니다** 로 알려 줌

### v1.9.8 — 지번 방식 (2026-08-10)

- **지번** 방식 추가 — 우편번호와 같은 순서로 주소 줄의 **꺽쇠(∧)를 눌러 상세 팝업**을 편 뒤, **지번의 번지 숫자만** 복사 (예: `경기 수원시 권선구 고색동 1191` → `1191`)
- 번지에 붙임표가 있으면 빼고 숫자만 복사 (`112-1` → `1121`)
- 동 이름에 숫자가 섞여 있어도(예: `종로1가 24`) 뒤에 오는 번지를 고르고, 팝업이 한 줄로 붙어 와도 우편번호를 번지로 잘못 읽지 않게 **지번 값 뒤는 잘라서** 읽음

### v1.9.7 — 북마크 리스트 이름 누르기 보강 (2026-07-21)

- **북마크 링크복사** — 리스트 이름을 눌러도 리스트로 안 넘어가던 문제 보강. 한 지점만 누르고 넘어가지 않고, `에 저장됨` **왼쪽(=이름 자리)의 후보들**(정확히 같은 이름 노드 → 이름을 포함하는 노드 → 왼쪽 클릭 요소 → 바로 왼쪽 좌표)을 차례로 눌러 보며, **누를 때마다 URL로 리스트 진입 여부를 확인**
- 이름 링크(`<a>`)가 `에 저장됨` 에 딱 붙어 있어 "왼쪽" 판정에서 제외되던 문제 수정 — **"왼쪽에서 시작하는지"로 기준을 바꾸고** 약간의 여유를 둠 (수정 버튼처럼 오른쪽으로 뻗는 건 여전히 제외)
- **네이버 앱은 주소창이 없어** URL로 리스트 도착을 판정할 수 없으므로, 리스트 상세에만 있는 **`저장된 장소 수`** 가 보이면 리스트로 판정하도록 추가 (브라우저는 계속 URL로 판정)
- 수정 버튼·별표(오른쪽/아이콘)는 후보에서 제외해 잘못 눌리지 않게 함

- 메뉴 옵션 — 네이버 앱으로 열어서 실행 (북마크는 기본 켜짐, 주소를 홈 탭으로 바꿔서 엶)
- 메뉴 옵션 — 대기 시간 4가지 조절 (반응 대기 · 상태 확인 · 팝업 열기/닫기 · 재시도)
- 누른 뒤 화면이 실제로 바뀔 때까지 확인하고 넘어가도록 전 단계 보강

### v1.6.0 — 자식 버튼 (2026-07-14)

- 오버레이 창 너비를 내용에 맞춰 다시 재도록 수정 (자식 버튼이 잘려 보이던 문제)

### v1.5.0 — 값(라벨 뒤 값) 방식 (2026-07-14)

- 값 방식 추가 — `상품번호` 같은 라벨을 찾아 바로 뒤의 값을 복사

- 값이 팝업 안에 있으면 **먼저 누를 항목**(예: `구매 추가정보`)을 눌러 연 뒤 읽음
- 복사할 값을 못 찾으면 토스트로 알림

### v1.4.0 — 명소 이름 정확도 (2026-07-14)

- 목록이 다 그려질 때까지 기다렸다가 복사 (로딩 중에 엉뚱한 이름을 복사하던 문제)
