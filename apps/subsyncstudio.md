### [0.1.3 — 2026-10-20 (최신)](https://github.com/tohinata/app-releases/releases/tag/subsyncstudio-v0.1.3)

#### Added — 텍스트로 자막 목록 만들기
- 패널 머리의 **[텍스트로 만들기]** (No 칸 · 목록 빈 곳 우클릭 메뉴에도). 대본 · 가사 같은 전체 텍스트를 붙여 넣거나
  .txt 파일을 열면 **줄바꿈마다 자막 하나**씩 목록을 만든다. 빈 줄은 건너뛴다
  - 「빈 줄로 나누기」를 켜면 빈 줄 사이의 여러 줄을 자막 하나(두 줄 자막)로
  - 시간은 첫 자막 시작(기본 0초, [지금 재생 시간] 단추)부터 줄 간격(기본 2초) · 길이(기본 1.8초)로 임시로 넣는다.
    만든 뒤 재생하며 시작 칸 클릭(1 · 3 키)으로 맞춰 나가면 뒤 줄이 따라온다
  - 목록이 있으면 「바꾸기 / 뒤에 붙이기」 선택. 만들 자막 수와 시간 범위를 미리 보여 준다. Ctrl+Z 로 되돌린다
  - 만든 줄에는 수정 표시를 붙이지 않는다 — 이제부터 맞춘 줄에만 표시가 붙는다
  - **영상 길이**를 넣으면 (영상이 열려 있으면 자동으로 채움) 「영상 길이에 맞춰 고르게 나누기」로
    간격 = (영상 길이 − 첫 시작 − 끝 여백) ÷ 자막 수, 길이 = 간격의 90% (최대 8초)로 처음 위치를 잡는다.
    끝 여백은 엔딩 크레딧을 생각해 영상의 3% (최대 60초). 1:23:45 · 45:10 · 초 로 입력
  - 창을 열 때 클립보드에 여러 줄 텍스트가 있으면 미리 넣어 둔다

#### Added — 수정 표시 한 번에 지우기
- 패널 머리의 **[표시 지우기]** — 모든 줄의 수정 표시(시작 · 종료 · 텍스트 마크)를 한 번에 지운다.
  시간 · 텍스트는 그대로, Ctrl+Z 로 되돌린다. 한 줄만은 지금처럼 No 칸 우클릭

### [0.1.1 — 2026-10-13](https://github.com/tohinata/app-releases/releases/tag/subsyncstudio-v0.1.1)

#### Added — 영상 위 마우스 휠 이동 · 자막 목록 표시 옵션
- **영상 위 마우스 휠 → 한 칸에 n초 이동** (기본 5초, 위로 굴리면 앞으로). 터치패드처럼 잘게 오는 휠은 모아서 한 칸으로 친다
  - 설정 > 재생 · 단축키 에 「영상 위 마우스 휠 (한 칸)」 초(고른 단위 따름)와 「휠 방향 반대로」
- **설정 > 일반 > 자막 목록**
  - 「종료 시간 칸 보이기」 (기본 켬). 끄면 종료 칸이 빠지고 패널 최소 너비도 그만큼 줄어든다.
    칸 순서가 바뀌어도 시작 칸 클릭 · 우클릭 동작은 그대로 (칸을 순서가 아니라 종류로 가림)
  - 「시간 표시」: **분:초.밀리초 02:24.532 (기본)** / 시:분:초.밀리초 00:02:24.532.
    목록 · 재생 시간 · 상태줄 · OSD · 파형 · 합치기 창 표시가 모두 따른다. 1시간이 넘으면 75:12.345 처럼 분이 60 이상
  - 시간 형식에 맞춰 시작 · 종료 칸 너비(74 / 94)와 패널 최소 너비(칸 너비 합 기준, 최소 400)가 바뀐다
  - 작업 백업(SQLite) · 공유 파일은 원래부터 **밀리초 정수**로 저장하고, 자막 파일은 각 형식의 원래 표기로 저장하므로
    표시 형식과 무관하게 꼬이지 않는다

#### Added — 영상 화면 밀어서 이동
- 영상 화면을 **좌우로 밀면(끌면) n초 앞 / 뒤로 이동**. 오른쪽 = 앞으로, 왼쪽 = 뒤로
  - 30px 넘게 밀면 1칸, 그 뒤로 정한 거리(기본 80px)마다 1칸씩 더 — 칸 수 × n초 이동
  - 끄는 동안 OSD 에 이동할 시간 · 도착 시각을 보여 주고, **손을 뗄 때** 이동한다. 제자리로 되돌려 놓으면 이동 안 함
  - 세로로 더 많이 움직이면 밀기로 보지 않는다. 밀기가 아니면 지금처럼 클릭 = 재생 / 멈춤, 더블클릭 = 전체 화면
  - 재생 / 멈춤은 버튼을 **뗄 때** 바뀐다 (밀기와 구분하려고)
- 설정 > 재생 · 단축키 > 키보드로 이동하는 시간 에 「영상 화면 좌우로 밀기 (한 칸)」 초(기본 5, 고른 단위 따름)와
  「한 칸 더 가는 거리」 px(기본 80, 30 ~ 400) 추가. 마우스 조작 표 · 사용법에도 추가

#### Changed — 좌클릭 동작
- 시간을 바꾸는 좌클릭을 **시작 칸으로만** 좁혔다. No · 길이 · 텍스트 칸을 누르면 줄만 선택된다.
  줄을 고르려던 클릭이 싱크를 바꾸는 일이 없게
- **종료 칸 좌클릭 → 그 자막의 종료만 지금 재생 시간으로.** 다른 자막은 그대로.
  시작보다 앞이면 바꾸지 않고, 다음 자막과 겹치면 상태줄에 알린다.
  "두 자막 함께 맞추기" 가 켜져 있으면 반대쪽에서 원래 종료가 가장 가까운 줄도 같이 맞춘다
- 텍스트 칸은 더블클릭 편집만. 첫 클릭을 더블클릭 시간만큼 기다리던 지연이 없어졌다
- 우클릭 메뉴에 「이 자막 종료를 지금 시간으로」

#### Added — No 칸 우클릭 메뉴
- **삭제** — 지울지 확인 창을 띄운다 (시간 · 텍스트 미리보기). 길이 · 텍스트 칸 메뉴의 지우기도 같은 확인을 거친다
- **위 자막이랑 합치기 / 아래 자막이랑 합치기**
  1. 두 텍스트를 위 → 아래 순서로 이어 붙인 편집 창을 먼저 띄운다. 확인해야 다음으로
  2. 시작 시간(위 / 아래 자막의 시작), 종료 시간(위 / 아래 자막의 종료)을 고르는 창.
     기본값은 위 시작 → 아래 종료. 종료가 시작보다 앞인 조합은 고를 수 없다
  - 합친 줄은 위쪽 줄 자리에 남고, 번호는 다시 매긴다. Ctrl+Z 로 되돌린다
  - 맨 위 / 맨 아래 줄에서는 해당 방향 합치기가 꺼져 있다
- **반대편 현재 자막과 시작 · 종료 같게** — 반대편에서 지금 영상에 나오고 있는(노란) 자막의
  시작 · 종료를 이 줄에 그대로 넣는다. 이 줄 하나만 바뀐다. 반대편에 나오는 자막이 없으면 꺼져 있다

#### Added — PC ↔ 모바일 작업 공유
- 위 도구줄 **[☁ 불러오기] [☁ 저장]** (영상 열기 옆). 공유 폴더(Google Drive 권장)에
  「영상 이름.subsync.json」 작업 파일을 주고받는다. 형식은 docs/PROJECT_FORMAT.md — 모바일 앱도 같은 형식
- 불러오기: 영상 이름이 같아야 불러온다 (크기만 다르면 경고). 덮어쓰기 전에 두 작업의 시각 · 기기 · 줄 수를
  나란히 보여주고 묻는다. 덮기 전 지금 작업은 데이터 폴더의 overwritten 에 보관
- 저장: 다른 기기가 저장한 작업이 있으면 덮어쓸지 묻는다
- 공유 폴더는 설정 > 작업 백업 에서 정한다. 비워 두면 Google Drive for Desktop 의 「내 드라이브\SubSync」 를 자동으로 찾는다

#### Changed — 시작을 맞출 때 옮기는 범위
- 시작을 맞추면 뒤 자막을 **다음에 시작을 맞춘 줄 직전까지만** 옮긴다 (기본).
  예) 8번을 맞춰 둔 뒤 3번을 맞추면 3~7번만 옮기고 8번부터는 그대로 — 맞춰 둔 줄이 다시 흐트러지지 않는다
- '시작을 맞춘 줄' = 수정 표시(시작)가 붙은 줄. 단축키(1 · 3) · 함께 맞추기로 따라 옮겨지는 반대편도 같은 규칙
- 설정 > 일반 > 싱크 맞추기 에서 「끝까지 전부 같이 옮기기」(예전 동작)로 바꿀 수 있다
- 상태줄에 옮긴 범위(3~7번)와 그대로 둔 줄(8번부터)을 알려준다

#### Fixed — 파형이 뒤로 갈수록 밀림
- 소리 샘플을 "8000개 = 1초" 로 가정하고 셌는데, VLC 가 실제로 내준 샘플레이트 · 채널이
  다를 수 있었다. 이제 WAV 머리에서 실제 값을 읽고, 44.1kHz 처럼 10ms 가 정수로 안 떨어져도 정확히 센다
- 소리가 중간에 끊긴 구간(타임스탬프 빈틈)만큼 뒤쪽이 앞당겨지던 것 — ffmpeg 로 만들 때 빈틈을 무음으로 채운다
  (aresample=async=1:first_pts=0)
- 그래도 남는 작은 차이(0.2% ~ 5%)는 영상 길이에 맞춰 늘이거나 줄인다
- 파형 캐시 형식을 바꿔서 예전에 만든 파형은 영상을 다시 열면 새로 만든다

#### Added — 단축키로 싱크 · 단축키 지정
- **1 = 왼쪽 시작, 2 = 왼쪽 종료, 3 = 오른쪽 시작, 4 = 오른쪽 종료** — 시작 · 종료 칸을 클릭한 것과 같다
  - 대상 줄 = 목록에서 고른 줄, 없으면 현재(노란) 줄
  - 종료를 찍으면 대상 줄이 다음 줄로 넘어간다 (설정에서 끌 수 있음) — 1 → 2 → 1 → 2 … 로 이어서 찍기
  - PageUp / PageDown = 대상 줄 옮기기, Q = 대상 줄을 현재 줄로
- **모든 단축키를 설정에서 바꾼다** (설정 > 재생 · 단축키). 칸을 누르고 키를 누르면 지정,
  × = 해제, ↺ = 기본값, 「모두 기본값으로」. Ctrl · Shift · Alt 조합 가능. 같은 키가 겹치면 빨갛게 알려준다
- 숫자 키는 숫자패드로 눌러도 된다
- **한글 입력 상태에서도 단축키가 먹는다** — 예전에는 한글 상태에서 M · Z · X · C 등이 동작하지 않았다
  (키가 ImeProcessed 로 들어와서. 이제 실제 키를 꺼내 쓴다)
- Esc(전체 화면 나가기)는 고정

#### Added — 수정 표시 마크
- 줄마다 **시작 · 종료 · 텍스트를 직접 고친 이력**을 남기고 No 칸 왼쪽에 마크로 보여준다
  - 시작: 시작 칸 클릭 싱크, 하나만 맞추기, 반대편과 같게, 함께 맞추기로 따라 옮겨진 짝 줄
  - 종료: 종료 칸 클릭, 함께 맞추기로 따라 맞춰진 짝 줄
  - 텍스트: 텍스트 편집, 합치기 / 새로 추가한 줄은 셋 다
  - 뒤 줄이 덩달아 옮겨진 것과 전체 · 현재부터 이동은 표시하지 않는다 (전부 표시되면 의미가 없다)
- 모양 7가지 — 설정 > 일반 > 수정 표시 (미리보기 있음)
  별(반쪽씩 시작 · 종료, 안에 T) · 반달(반쪽씩, 가운데 점) · 점 세 개 · 글자 S E T · 모서리 · 연필 · 표시 안 함
- 마크에 마우스를 올리면 「수정함: 시작 · 텍스트」 처럼 알려준다
- 작업 백업에 같이 저장되고 되돌리기(Ctrl+Z)도 따라간다. No 칸 우클릭 → 이 줄 / 모든 줄 수정 표시 지우기
- No 칸 너비 46 → 62px (마크 자리), 텍스트 칸 170 → 154px 로 패널 최소 너비는 그대로

#### Added — 자막 추가
- No 칸 우클릭 메뉴에 **위에 자막 추가 · 아래에 자막 추가 · 지금 재생 시간에 자막 추가**.
  텍스트를 먼저 입력받고, 앞뒤 자막 사이 빈 곳에 최대 2초로 넣는다.
  빈 곳이 0.3초도 안 되면 2초로 넣고 겹친다고 알린다. 넣은 뒤 시작 · 종료 칸 클릭으로 시간을 맞추면 된다
- 목록의 빈 곳(줄 아래 · 빈 목록)을 우클릭하면 「지금 재생 시간에 자막 추가」 — 자막 파일 없이 처음부터 만들 수도 있다

#### Added — 현재 자막부터 이동
- 각 패널의 「전체 자막 이동」 아래에 **현재 자막부터 이동** 줄. 현재(노란) 줄과 그 뒤 줄만
  −1 · −0.5 · −0.1 · +0.1 · +0.5 · +1초, 또는 직접 입력한 시간(전체 이동의 입력칸과 같은 값)만큼 옮긴다.
  앞 줄은 그대로. 현재 줄이 없으면 목록에서 고른 줄이 기준
- 머리글에 기준 줄 번호를 보여주고, 옮긴 뒤 앞 줄과 겹치면 상태줄에 알린다

  `%TEMP%\.net\SubSyncStudio\` 에 같은 구조로 풀어 쓴다. 압축(EnableCompressionInSingleFile)으로 크기를 줄였다

  0.01초씩, Shift 0.001초, Ctrl 0.1초. 슬라이더는 0.1초 단위로 대충 고르는 용도
- 키보드로 이동하는 시간에 **단위 고르기** 단추 — 1초 · 0.1초(기본) · 0.01초 · 0.001초.
  고른 단위까지 입력하고, 입력칸에서 ↑ ↓ · 휠로 그 단위만큼 (Ctrl 10배씩).

#### Design notes
- **함께 맞추기의 짝은 '원래' 시간으로 찾는다.** 클릭한 줄은 이미 옮겨진 뒤라서
  새 시간으로 찾으면 엉뚱한 줄이 걸린다
- **⇄ 맞추기는 대사 구간의 겹침으로 찾는다.** 처음엔 시작 시간끼리 짝지어 투표시켰는데,
  줄 나누기가 다르면(한쪽은 두 줄, 한쪽은 한 줄) 짝이 틀어져 오차가 컸다.
  지금은 양쪽의 '말하는 구간' 을 합쳐 두고 한쪽을 밀어 보며 가장 많이 겹치는 위치를 찾는다
  (±10분을 100ms 로 훑고, 근처를 5ms 로 다시, 최고점이 평평하면 그 가운데).
  줄을 20% 쪼개고 15% 합친 자막 + 줄마다 ±150ms 흔들림으로 시험했을 때 실제 차이 3.470초를 3.472초로 찾았다.
  겹침이 30% 미만이면 옮기지 않는다

#### Design notes
- **암시적 TextBlock 스타일을 두지 않았다.** 받아쓰기 스튜디오는 모든 TextBlock 을 Fg 로
  눌러두는데, 그러면 '현재 자막 줄' 처럼 배경이 바뀌는 곳에서 글자색이 따라오지 못한다.
  창이 Foreground 를 갖고, 배경을 바꾸는 템플릿이 글자색도 같이 바꾸게 했다 (Themes/*.xaml 의 짝 규칙)
- **텍스트 칸의 싱크는 더블클릭 시간만큼 늦게 맞춘다.** 더블클릭(편집)의 첫 클릭이
  싱크로 먹으면 편집하려다 시간이 바뀐다
- **싱크 시간은 멈추기 전에 읽는다.** 멈추는 동안 몇 십 ms 가 흐른다.
  멈춘 상태에서 위치를 옮긴 직후에는 VLC 가 옛 시간을 잠깐 들고 있어서, 옮긴 목표 시간을 우선한다
- **백업 키는 파일 이름 + 크기.** 경로를 넣으면 영상 폴더를 옮겼을 때 이어서 하지 못한다
- **유지 기간은 마지막으로 작업한 날부터 센다.** 만든 날부터 세면 계속 작업 중인 백업도 지울지 묻게 된다
