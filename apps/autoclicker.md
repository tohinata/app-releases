## 바뀐 점 (1.17.0)

- 매크로 녹화 — 메인 화면 '● 녹화로 매크로 만들기'. 투명한 막 위에서 탭·드래그로 조작하면 그대로 스텝이 되고(탭→클릭, 드래그→스와이프, 사이 간격은 실제 누른 시간 그대로), '완료' 를 누르면 매크로가 만들어짐. 조작은 아래 앱에 그대로 전달됨
  - 시작·완료 버튼 조작은 스텝에 안 들어감. '되돌리기' 로 마지막 스텝 취소
  - 한 손가락만 지원(멀티터치 X), 손을 뗀 순간 앱에 전달되어 약간 지연될 수 있음
- 플로팅 패널의 설정·저장 팝업이 길어져 키보드에 취소/저장 버튼이 가리던 문제 수정 — 팝업을 위쪽으로 올리고, 내용이 화면 절반을 넘으면 팝업 안에서 스크롤
- 설정에 '접어도 눈(보이기/숨기기) 버튼 보이기', '접어도 즐겨찾기 버튼 보이기' 옵션 추가(기본 켜짐) — 켜면 메뉴를 접어도 그 버튼이 남아 바로 쓸 수 있고, 끄면 접을 때 함께 숨음. 패널을 다시 열면 적용
- 메인 화면 상단 '접근성 설정 열기' 버튼을 '배터리 최적화 제외' 버튼과 한 줄에 나란히 배치
