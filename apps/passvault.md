## 바뀐 점 (0.1.0)

### Added — 첫 버전
- **항목 종류**: 로그인(사이트 · 앱) · 카드 · 은행 계좌 · 집 · 주소 · 와이파이 · 신분증 · 번호 · 보안 메모 · 기타(직접 만들기)
  - 종류마다 기본 칸 (예: 카드 = 카드사 · 카드 번호 · 유효기간 · CVC · 비밀번호 앞 2자리 · 명의자 · 결제 계좌)
  - 칸 추가 · 지우기 · 순서 바꾸기, 칸마다 종류(글자 · 비밀번호 · 번호 · PIN · 주소 · 이메일 · 전화 · 날짜 · 여러 줄)와 「가림」
- **소유자**: 항목마다 누구 것인지(나 · 아버지 · 어머니 · 누나 …) 콤보 상자로 고름. 목록에 「이름 · 소유자」, 왼쪽 분류에 소유자별로도 모임. 소유자 목록은 설정 > 일반 에서 추가 · 순서 · 빼기 (다른 기기와 같이 씀)
- **전에 쓴 이름 고르기**: 항목 이름 · 칸 이름 칸을 콤보 상자로 — ▼ 로 전에 쓴 이름을 고르거나 치면 걸러짐
- **등록 · 편집 · 삭제 · 복사**. 즐겨찾기, 분류(왼쪽), 검색(가린 칸 값은 찾지 않음)
- **가림 칸은 기본으로 ******* — 눈 버튼으로 보기. 본 값은 n초 뒤 자동으로 다시 가림 (기본 10초, 설정에서 바꿈).
  보이는 상태는 저장하지 않아 다시 켜거나 잠갔다 열면 항상 가려진 채로 시작. 복사는 가린 채로도 됨, 칸 값을 두 번 눌러도 복사
- **복사한 값 자동 지우기** (기본 10초, 설정에서 바꿈). 프로그램을 끌 때도 지움 (잠금 · 최소화 때는 붙여 넣을 수 있게 시간까지 둠). 상태 줄에는 「아이디를 복사했습니다」처럼 안내만 — 값은 보이지 않음.
  비밀 값은 윈도우 클립보드 기록(Win+V) · 클라우드 클립보드에 남지 않게 표시
- **암호화**: 마스터 비밀번호 → PBKDF2-HMAC-SHA256(21만 번) → AES-256-GCM. 폰 앱과 같은 파일 형식 (docs/VAULT_FORMAT.md)
- **잠금 화면**: 마스터 비밀번호 / 패턴 / Windows Hello(지문 · 얼굴 · PIN). 패턴 5번 틀리면 마스터 비밀번호로만
- **자동 잠금**: 쓰지 않으면 n분 뒤(기본 5분), 윈도우를 잠그면(Win+L)
- **최소화했다가 다시 열 때** 최소화한 지 n초 이상 지났으면 잠금 화면에서 시작 (기본 10초 · 바로 ~ 5분 · 안 함)
- **비번 생성기**: 무작위(길이 · 대문자 · 숫자 · 특수문자) / **내 비번 패턴 따라** (설정에서 켜는 옵션)
  - 금고의 모든 사이트 · 앱 · 계좌 · 와이파이 비밀번호를 글자 종류 덩어리로 나눠 자주 쓰는 형태 · 특수문자를 찾고 같은 형태로 새로 뽑는다
  - 「자주 쓰는 단어 넣기」 하위 옵션, 강도 표시. 기존 비번과 같은 것은 만들지 않음
- **구글 드라이브 동기화**: Google Drive for Desktop 폴더(G:\내 드라이브\PassVault\passvault.pvault)의 암호화된 금고 파일 하나를 PC · 폰이 같이 쓴다
  - 저장하면 2초 뒤, 열 때, 창으로 돌아올 때(1분 넘게 지났으면) 동기화. 같은 항목은 더 나중에 고친 쪽, 지운 항목은 다른 기기에서도 지움
  - 처음 실행 때 「구글 드라이브의 금고 불러오기」로 다른 기기의 금고를 그대로 씀
  - 다른 기기에서 마스터 비밀번호를 바꾸면 다음 동기화 때 따름
- **백업**: 하루 한 번 자동(기본 30개 보관), 지금 백업, 내보내기, 다른 금고 파일 가져오기(합치기)
- **설정**: 일반 · 잠금 · 비번 생성기 · 동기화 · 백업 · 정보(개발자 · 버전 · 수정 이력 · 업데이트 확인)
- **Caps Lock 막기**: 켜져 있으면 잠금 화면에 경고, 새 금고 만들기 · 항목 저장 · 마스터 비밀번호 바꾸기는 막는다
- 다크(기본) / 라이트 테마, 자동 업데이트(app-releases), 한 번에 하나만 실행
