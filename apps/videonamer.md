### [0.1.0 — 2026-11-02 (최신)](https://github.com/tohinata/app-releases/releases/tag/videonamer-v0.1.0)

- 처음 만든 판. 영상을 모아 둔 폴더를 넣으면 작품 목록을 보여 주고, 작품마다 폴더 · 파일 이름을 한 가지 규칙으로 정리한다
- 작품 정보 검색: 위키데이터 · 위키백과(키 없음), TMDB(무료 API 키 — 한국어 제목 · 회차 부제), AI 검색(Claude API 키 — 웹을 찾아 정리)
- 파일 이름에서 시즌 · 회차(S01E01 · EP01 · 第1話 · #5 · （１）) · 방송 날짜(241107 · [2024.11.07] · 2024年11月7日) · 부제(「…」) · 코덱 · 해상도를 읽는다
- 이름 규칙은 설정에서 틀로 고칠 수 있다. 각 틀 옆 '조합…' 버튼으로 부품(제목 · 회차 S01E01/第01話/#1 · 날짜 241107/2024-11-07 · 부제 · [h265] …)을 눌러 쉽게 만들 수도 있다 — (드라마 · 영화 · 예능 · 기타, 시즌 폴더, [h265] 표시, 부제 언어)
- 실행 전에 지금 이름 → 새 이름을 표로 보여 주고, 겹치는 이름은 빨갛게 표시한다. 칸을 고치면 바로 다시 계산
- 일드 분기 {q}: 첫 방영일로 1~3월 = 1분기(冬 · 1月期) … 계산해 이름에 넣을 수 있다 (2018년 1분기 · 2018Q1 · 2018年冬 · 2018年1月期 …)
- 표의 '새 이름' 칸을 두 번 누르면 직접 고칠 수 있다 (상태에 ✎, 비우면 규칙대로). 짝 자막도 따라간다
- 자막(.smi .srt …)은 짝 영상 이름을 따라 같이 바뀐다
- 작품 폴더 하나를 통째로 넣으면(하위 폴더가 없거나 시즌 폴더뿐) 그 폴더를 작품 하나로 본다. 이름을 바꾸면 넣어 둔 폴더 경로도 따라 바뀐다
- 영상 폴더는 버튼으로 고르거나 탐색기에서 끌어다 놓아 추가한다 (왼쪽 목록 · 설정 > 폴더, 여러 개 한 번에)
- 오른쪽 클릭 메뉴도 다크 테마로 (밝은 왼쪽 칸 · 시스템 색 강조 없이)
- 바꾼 이름은 '되돌리기' · '기록'으로 되돌릴 수 있다
- 전각 문자 확인 · 정리: 표의 '전각' 칸에 지금 이름의 전각 문자(！？（）＆ 전각 공백 …)를 보여 주고, 설정에서 그대로 · 반각으로 · 지우기와 바꿀 글자표(【 → [ 등)를 정할 수 있다. 작품 정보가 없는 작품도 이것만 정리할 수 있다
- 작품 정보는 이 PC 안(%LOCALAPPDATA%\VideoNamer)에만 저장하고 영상 폴더에는 아무 파일도 만들지 않는다. 드라이브 글자가 바뀌어도 폴더 이름으로 다시 찾는다
- 설정 > 데이터: 작품 정보 모음 · 되돌리기 기록 · 코덱 확인 기록 · 임시 파일 지우기, 예전 판이 영상 폴더에 만든 .videonamer.json 찾아서 지우기
